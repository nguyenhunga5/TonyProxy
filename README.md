Thank you for checking out **TonyProxy**.

TonyProxy is a native macOS application built for developers who need a fast, modern, and lightweight network debugging tool. It helps you inspect, replay, organize, and export HTTP(S) traffic while feeling right at home on macOS.

---

## Why TonyProxy?

TonyProxy started as a personal side project.

After years of debugging network traffic for iOS and macOS applications, I wanted a tool that felt native, stayed responsive even with large capture sessions, and focused on the workflows I used every day.

Instead of trying to become the biggest proxy tool, TonyProxy focuses on delivering a polished experience for developers who appreciate speed, simplicity, and thoughtful design.

---

## Features

- HTTP & HTTPS traffic inspection
- Native macOS interface
- Session Manager
- Request replay
- Traffic analytics
- HTTPS certificate management
- HAR export
- cURL export
- NDJSON export
- CSV export
- Postman export
- OpenAPI export
- TonyPack archive format

---

## Getting Started

1. Install TonyProxy.
2. Launch it from the **Applications** folder.
3. (Optional) Install the TonyProxy Certificate from **Settings → Certificate** to inspect HTTPS traffic.
4. Start capturing network requests.

That's it.

## Design Philosophy

TonyProxy is built around a few simple principles:

- Native before cross-platform
- Fast before feature-heavy
- Simple before complicated
- Developer experience above everything else

Every feature exists because it solved a real problem during day-to-day development.
